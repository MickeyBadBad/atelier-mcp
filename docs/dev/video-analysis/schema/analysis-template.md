This file documents the canonical schema. The Gemini prompt at `prompts/gemini-full-video.md` produces this shape; the transcript-only prompt aims at the same shape with degraded numeric fields.

## Schema rules

1. Every section MUST be present — fill with `(not shown in video)` rather than skip.
2. Numeric values: prefer UI-visible values. Mark inferred values explicitly.
3. The `Recommended Atelier project changes` section uses **directive verbs** the consumer parses: `ADD-RULE`, `TUNE-GATE`, `EDIT-SKILL`, `ADD-TOOL`. Stick to these four prefixes — synthesis assumes them.
4. Cross-references to Atelier files use full repo-relative paths (`docs/handbook/lighting.md`, `src/atelier/_gates.py`).
5. Keep direct quotes ≤ 3 lines each, ≤ 3 quotes per analysis.
